Flagship · Deployed 01

SupplyBeacon

Explainable graph-based supply-chain risk intelligence & decision-support platform

SupplyBeacon is a publicly deployed research prototype for electronics supply-chain risk intelligence. It connects product and supply-network data with weather/news disruption evidence, a directed NetworkX graph, deterministic operational risk scoring, and traceable evidence-to-impact analysis.

The platform combines GraphRAG for evidence retrieval, LangGraph for agentic query orchestration, historical shipping ML, a warehouse-disruption Scenario Lab, and network management. The application uses a React + TypeScript frontend on Vercel and a FastAPI + Docker backend on Render.

Research · Reproducible 05

Graph Propagation & Temporal Learning

Directed network science, competitive diffusion, temporal simulation and graph-model forecasting

Investigated information propagation in an Indian political Twitter network using 85,495 tweets, 109,443 supplied directed edge rows and 129,604 reconstructed timestamped interactions. Built directed connectivity and time-respecting reachability analyses, competitive two-class diffusion, randomized null models and leakage-controlled weekly forecasting.

A key result: the original transmission regime had an empirical Reff of 0.00250. Calibrated experiments found no detected material difference between observed and degree-preserving rewired directed networks, but a substantial difference versus symmetrized graphs. Compared GCN, GraphSAGE, GAT and temporal models against history-aware baselines; recent user history provided the stronger modest forecasting signal.

Extended the study with Shapley-style transmission-kernel attribution, event-driven temporal propagation, statistical controls and reproducibility audits. Dataset class labels were treated as operational labels, not verified political positions; no real-world causal information-flow claims are made.
